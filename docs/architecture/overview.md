## 技术栈选型

| 层级 | 技术 | 选型理由 |
|------|------|---------|
| **前端框架** | React 18 + Vite | 现代前端生态、高性能 |
| **前端样式** | Tailwind CSS + Ant Design | 快速开发、组件丰富 |
| **图表** | ECharts / Recharts | 交互式可视化 |
| **后端框架** | FastAPI | 异步高性能、自动 API 文档 |
| **数据存储** | MongoDB + HDF5 | 非结构化数据 + 高性能时序 |
| **数据源** | PyTdX / TqCenter / AkShare | 多源降级策略 |

## 核心模块关系

### 数据流向
```
数据源 → data_manager → (MongoDB/HDF5) → factor_engine → FastAPI → React UI
```

### 模块依赖
- **data_manager**：基础模块，无内部依赖
- **factor_engine**：依赖 data_manager
- **sentiment_engine**：依赖 data_manager
- **FastAPI 路由**：调用各引擎模块

## 安全设计原则

1. **输入验证**：所有 API 调用都有超时和重试机制
2. **CORS 配置**：仅允许前端域名访问
3. **防未来函数**：所有时间序列操作严格检查数据时效性
4. **错误处理**：模块间有清晰的异常传递和恢复机制

## 2. 布局系统

### 2.1 页面框架

```
┌─────────────────────────────────────────────────┐
│  顶栏 (Header): Logo | 页面标题 | 搜索 | 设置 | 一键更新 | 健康状态 │
├─────────────────────────────────────────────────┤
│  内容区 (Content): 路由对应页面组件               │
│   - 单栏布局：日历、设置                         │
│   - 多卡片网格：市场监控、市场分析                │
│   - 左右分栏：个股分析                           │
└─────────────────────────────────────────────────┘
```

### 2.2 响应式断点

| 断点 | 宽度 | 布局模式 |
|------|------|----------|
| `xs` | < 576px | 单列堆叠，导航汉堡菜单 |
| `sm` | 576px - 768px | 单列，侧边栏展开 |
| `md` | 768px - 992px | 双列网格 |
| `lg` | 992px - 1200px | 三列网格，正常布局 |
| `xl` | > 1200px | 四列/自适应，完整布局 |

### 2.3 内容区域溢出行为

| 组件类型 | 水平溢出 | 垂直溢出 |
|----------|----------|----------|
| 图表容器 (ECharts/Recharts) | 响应式缩放，不产生水平滚动 | 固定高度，内部缩放 |
| 数据表格 (Ant Design Table) | 水平滚动 + 固定关键列 | 分页，限制最大高度 |
| 卡片网格 | 自动换行，Flex wrap | 自然扩展 |
| 文本区域 (AI分析) | 自动换行 | 最大高度 + 内部滚动 |

## 5. 动效规范

| 场景 | 动画 | 时长 | easing |
|------|------|------|--------|
| 页面切换 | 淡入 | 200ms | ease |
| 卡片悬浮 | 阴影提升 | 200ms | ease-out |
| 图表数据更新 | 平滑过渡 | 300ms | cubic-bezier |
| 按钮点击 | 涟漪 | 300ms | ease |
| Toast提示 | 滑入 + 自动消失 | 3s + 300ms滑出 | ease-in-out |
| 模态框 | 缩放 + 淡入 | 200ms | ease |
| 拖拽排序 | 跟随 + 弹性 | 200ms | spring |
| 加载骨架屏 | 渐变脉冲 | 1.5s 循环 | linear |

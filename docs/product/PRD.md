# A股量化系统 — 产品需求文档 (PRD)

**文档版本**: 1.0 (2026-07-24)
**状态**: 初始草案
**上游**: 无（根文档）

---

## 1. 产品愿景

打造一款面向A股个人投资者的专业级量化复盘与市场监控系统。核心差异在于：**不依赖实时行情交易**，聚焦盘后数据聚合与AI驱动分析，帮助投资者在每日收盘后快速掌握全市场资金动向、板块效应、个股强度，并生成专业级复盘报告。

系统采用 **React + FastAPI 分离架构**，数据源涵盖通达信(PyTdX)、AkShare、BaoStock、yfinance等多源瀑布，盘后完成全量数据同步与预计算，前端直接读取缓存实现秒级响应。

## 2. 成功指标

### KPI (关键绩效指标)

| 指标 | 目标值 | 测量方式 |
|------|--------|----------|
| 日线数据完整度 | ≥ 99% (全市场5000+只股票) | `stock_daily` 日线计数 vs 理论日线数 |
| 板块覆盖率 | ≥ 340个板块 (通达信全量) | `sector_basics` 文档计数 |
| 板块日线覆盖率 | ≥ 40个板块有直接指数日线 | `sector_daily` 有数据板块数 |
| 预计算自动完成率 | ≥ 95%交易日自动完成 | `base_data_daily.is_final` 占比 |
| AI分析覆盖率 | ≥ 90%交易日有AI分析 | `market_daily.ai_analysis` 非空占比 |

### SLA (服务水平协议)

| 维度 | 目标 |
|------|------|
| 前端页面加载 | p95 < 2s (含API调用) |
| 基础数据接口响应 | p99 < 500ms |
| 一键更新全流程 | 单次执行 < 2小时 |
| AI分析生成 | 单次 < 3分钟 |
| 系统可用性 | 99.5% (盘后时段 15:30-23:59) |

## 3. 全局业务约束

| 类别 | 约束描述 |
|------|----------|
| **数据时效** | 所有数据计算必须严格区分"盘中数据"和"收盘最终数据"(`is_final`字段)，预计算只能在收盘后执行 |
| **数据源依赖** | 通达信协议(PyTdX)为首选数据源，AkShare/BaoStock/yfinance为回退，绝不生成虚假数据 |
| **盘后执行** | 全部数据同步必须在中国A股交易日的 15:30-23:59 时间窗口内执行 |
| **防未来函数** | 所有时间序列操作严格检查数据时效性，禁止使用未来数据计算历史指标 |
| **次新股过滤** | 上市未满365天不参与NH-NL计算，未满120个交易日不参与RPS截面排名 |
| **AI调用限制** | DeepSeek API每日每个交易日仅调用一次，结果缓存到 `market_daily.ai_analysis`，设置时间窗口限制防止盘中被触发 |

### 明确不包含 (Out-of-Scope)

| 编号 | 不包含的功能 | 理由 |
|------|-------------|------|
| OOS-01 | **实时行情推送** | 系统定位为盘后复盘工具，非日内交易系统 |
| OOS-02 | **自动交易执行** | 不接入任何券商API，不产生任何交易指令 |
| OOS-03 | **期货/期权/可转债数据** | 仅聚焦A股股票、板块、指数 |
| OOS-04 | **美股/港股全量数据** | 仅通过yfinance提供有限的美股ADR支持 |
| OOS-05 | **财务基本面深度分析** | 当前版本不包含财报数据、估值模型(PE_TTM是唯一财务指标) |
| OOS-06 | **用户账户系统** | 系统为单用户本地部署，无登录/认证/多租户 |
| OOS-07 | **移动端App** | 当前仅支持Web端，无React Native/Flutter计划 |
| OOS-08 | **历史回测框架** | 不提供策略回测引擎 |

## 6. 数据流概要

```
外部数据源 (PyTdX / AkShare / BaoStock / yfinance)
    │
    ▼
DataManager 多源同步 → MongoDB (stock_daily / sector_daily / index_daily)
    │
    ▼
Factory 层 (IndexFactory / StockFactory / SectorFactory)
    │   计算 RPS / MA / 涨跌幅 / 百分位
    ▼
MarketAggregator 跨域聚合
    │   预计算 CR5/CR10/NH-NL/MA占比
    ▼
market_daily + base_data_daily (缓存)
    │
    ▼
Orchestrator 层 → API 路由 → React 前端
```

## 8. 术语表

| 术语 | 定义 |
|------|------|
| CR5% | 成交额前5%个股的成交额占比，衡量市场资金集中度 |
| CR10% | 成交额前10%板块的成交额占比，衡量板块资金集中度 |
| NH-NL | 250日新高(NH)与新低(NL)股票数差值，衡量市场趋势强度 |
| RPS | 相对强度排名，rank(区间涨幅)/总数×100，多周期(10/20/50/120/250) |
| is_final | 标记数据是否为收盘后最终版本，盘中数据is_final=false |
| Factory | 单一领域的数据同步与计算封装 |
| Orchestrator | 多步骤全流程编排器 |

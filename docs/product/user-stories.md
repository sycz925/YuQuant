## US-001: 查看CR5%拥挤度趋势图

**标题**: 用户查看个股成交额前5%拥挤度趋势
**优先级**: P0
**父级**: PRD §4 — 市场监控

**描述**: 作为个人投资者，我想查看CR5%的历史趋势图，以便判断当前市场资金集中程度是否异常。

**验收标准 (BDD)**:
- Given 我已打开市场监控页面
- When 页面加载完成
- Then 应显示CR5%趋势折线图，默认展示近一年日数据
- When 我切换聚合周期到"周/月/季/年"
- Then 图表数据应按照对应周期重新聚合展示
- When 我开启"叠加指数"选项
- Then 图表中应叠加指定大盘指数的走势曲线
- When 数据未就绪或数据库为空
- Then 应显示空状态提示，而非崩溃

**优先级**: P0
**父级**: PRD §4 — 市场监控

## US-005: 查看AI综合研判

**标题**: 用户查看DeepSeek AI分析
**优先级**: P0
**父级**: PRD §4 — 市场监控

**验收标准 (BDD)**:

## US-006: 查看新高板块效应聚类

**标题**: 用户查看新高股票板块聚类
**优先级**: P0
**父级**: PRD §4 — 复盘报告

**验收标准 (BDD)**:
- Given 我在市场监控页面
- When 新高板块组件加载
- Then 应显示Top10强势行业板块
- Then 每个板块应展示先锋(3只)/中军(3只)/后排(2只)三梯队个股
- Then 先锋按chg_50d降序排列
- Then 中军为成交额Top10内按chg_50d降序
- Then 后排为成交额升序Top20排除ST按当日涨幅降序
- Then 排除板块不应出现在列表中
- When 数据来自`market_daily`缓存
- Then 优先读取缓存，无缓存时实时计算

## US-010: 同步个股日线数据

**标题**: 用户同步个股日线
**优先级**: P0
**父级**: PRD §4 — 数据管理

**验收标准 (BDD)**:
- Given 我在Settings页面
- When 我点击"同步个股"按钮
- Then 应启动逐天回溯模式的后台同步任务
- Then 数据源顺序为 PyTdX → AkShare → BaoStock → yfinance
- Then 已同步的股票应跳过(增量模式)
- Then `stock_daily`应包含所有启用股票的OHLCV数据
- When 某只股票所有数据源均失败
- Then 应记录失败，继续同步下一只，不中断整体任务

## US-012: 计算RPS

**标题**: 用户计算相对强度
**优先级**: P0
**父级**: PRD §4 — 数据管理

**验收标准 (BDD)**:
- Given 数据同步完成后
- When 我点击"计算RPS"按钮
- Then 系统应为所有个股计算rps_20/50/120/250
- Then 系统应为所有板块计算rps_10/20/50
- Then 个股RPS写入`stock_daily.rps_*`，板块RPS写入`sector_daily.rps_*`
- Then 上市未满120天的个股、日线未满20条的板块不参与计算

---

## US-013: 预计算基础数据

**标题**: 用户一键预计算基础指标
**优先级**: P0
**父级**: PRD §4 — 数据管理

**验收标准 (BDD)**:
- Given RPS计算完成后
- When 我点击"同步基础数据"按钮
- Then 系统应计算CR5/CR10/MA50占比/MA20占比/NH-NL
- Then 计算结果写入`base_data_daily`
- Then 系统应生成大盘总览、新高聚类、低位板块等快照
- Then 快照写入`market_daily`
- Then 市场监控页面应直接从这些缓存读取，无需实时计算

---

## US-014: 一键全量更新

**标题**: 用户一键完成所有同步与计算
**优先级**: P0
**父级**: PRD §4 — 数据管理

**验收标准 (BDD)**:
- Given 我在任意页面
- When 我点击顶部导航栏的"一键更新"按钮
- Then 系统应按顺序执行7步骤: 同步指数→同步个股→同步板块→个股RPS→板块RPS→同步PE→预计算
- Then 每步进度应在界面实时显示
- When 某步骤失败率超过5%
- Then 自动停止，提示用户检查网络/数据源
- When 当前不在允许的时间窗口(15:30-23:59)
- Then 应提示用户不在同步时间窗口内

# 前端应用功能文档

## 概述

React 交互式前端，提供市场监控、个股分析和数据管理功能。

## 功能说明

### 1. 市场监控

- **CR5% 走势图**: 实时监测成交额前5%的拥挤状态
- **RPS 强度分析**: 基于欧奈尔强度的个股及板块 RPS 计算与展示
- **板块分析**: 支持同步通达信板块概念，并自动聚合板块日线数据

### 2. 市场分析

- **气泡图**: 市场活跃度可视化
- **活跃池**: 筛选活跃个股

### 3. 个股技术分析

- **K线图展示**: 支持均线叠加（MA10/MA20/MA60）
- **成交量分析**: 同步展示成交量柱形图

### 4. 数据管理

- **数据同步**: 多源数据同步（PyTdX/AkShare/BaoStock/yfinance）
- **板块管理**: 板块概念同步与配置
- **RPS 计算**: 批量计算个股 RPS 指标

## 运行方式

```bash
cd app/client
npm run dev
```

## 技术栈

- React 18 + Vite
- Ant Design 组件库
- ECharts / Recharts 可视化
- Tailwind CSS 样式方案
- React Router v6 路由
- Axios HTTP 客户端

## 页面列表

- **市场监控** - CR5%/MA/NH-NL 趋势图、大盘总览、AI分析
- **市场分析** - 多维统计、气泡图、活跃股池
- **日历复盘** - 每日摘要快照、周/月 AI 总结
- **个股分析** - 股票 K 线 + RPS 历史曲线
- **Settings** - 数据同步、RPS 计算、预计算、排除管理

## 界面特点

- 响应式布局
- 固定导航栏
- 后端健康状态实时监控
